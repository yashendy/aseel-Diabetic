# مخطط البروتوكول العلاجي الموحّد (الإصدار 2)

المصدر الوحيد للقراءة والكتابة والتحقق: `js/child-protocol.js`.
هذه حسابات مساعدة وليست بديلاً عن تعليمات الطبيب المعالج.

## القرارات المعتمدة

| القرار | التطبيق |
|---|---|
| معامل التصحيح (CF) رقم واحد للطفل | حقل `cf`، يعدّله الطبيب وولي الأمر |
| نطاق السكر حسب المعدل العالمي مع تخصيص يدوي | حدود قياسية (ISPAD/ADA) تُستخدم ما لم يُخصَّص حد في `glucose_limits` |
| الحد الأقصى للجرعة وبارامترات الأمان | يعدّلها الطبيب وولي الأمر |
| لا قيم افتراضية صامتة للجرعات | إن نقص CR أو CF أو الهدف: تُعرض رسالة بما ينقص ولا تُحسب جرعة |

## الحقول المعتمدة في وثيقة الطفل (`parents/{pid}/children/{cid}`)

| الحقل | المعنى | يعدّله |
|---|---|---|
| `glucoseUnit` | `mmol/L` أو `mg/dL` | ولي الأمر فقط (تغييرها يحوّل CF والحدود عبر `convertProtocolUnit`) |
| `cr.{breakfast,lunch,dinner,snack}` | جرام كارب لكل وحدة أنسولين | الطبيب + ولي الأمر |
| `cf` | مقدار انخفاض السكر لكل وحدة (بوحدة الطفل) | الطبيب + ولي الأمر |
| `glucose_limits.target` | هدف السكر لحساب جرعة التصحيح (لا قيمة افتراضية) | الطبيب + ولي الأمر |
| `glucose_limits.{critical_low,low,high,critical_high}` | حدود مخصّصة (اختيارية)، وإلا تُستخدم القياسية | الطبيب + ولي الأمر |
| `insulin.{basal,bolus}` | أنواع الأنسولين | الطبيب + ولي الأمر |
| `basalDose` (+ نسخة `insulin.basalDose`) | الجرعة القاعدية | الطبيب + ولي الأمر |
| `maxDose` | أقصى جرعة وجبة/تصحيح واحدة | الطبيب + ولي الأمر |
| `insulinStep` | تدرج الجرعة (0.05 / 0.1 / 0.25 / 0.5 / 1) | الطبيب + ولي الأمر |
| `diaHours` · `hypoCarbs` · `netCarbRule` | مدة المفعول · كارب علاج الهبوط · قاعدة الألياف | الطبيب + ولي الأمر |
| `weight` (+ نسخة `vitals.weight`) · `vitals.{height,bmi,measurementDate}` | الوزن والقياسات | الطبيب + ولي الأمر |

النسخ المرآة (`insulin.basalDose` و`vitals.weight`) تُكتب دائماً مع الأصل من نفس الدالة، فلا تختلف.

## الحدود القياسية العالمية (للأطفال والمراهقين، النوع الأول)

| | mmol/L | mg/dL |
|---|---|---|
| هبوط حرج (مستوى 2) | 3.0 | 54 |
| حد الهبوط (بداية النطاق) | 3.9 | 70 |
| حد الارتفاع (نهاية النطاق) | 10.0 | 180 |
| ارتفاع حرج | 13.9 | 250 |

الواجهات تعرض شارة "قياسي" أو "مخصّص" حسب حالة الطفل.

## مدى القيم المقبولة عند الحفظ

CR: 1–150 · CF: 0.3–22 (mmol/L) أو 5–400 (mg/dL) · الجرعة القاعدية: 0–100 · الحد الأقصى: 0.5–100 ولا يقل عن التدرج · مدة المفعول: 2–8 ساعات · كارب الهبوط: 5–40 · الوزن: 2–200 · الطول: 30–220.
يُرفض أي معامل تصحيح يبدو بوحدة غير وحدة الطفل (مثلاً 3 لطفل بوحدة mg/dL) بدل تحويله بصمت.

## من يكتب في سجل التعديلات (`regimen_history`)

الطبيب (`by: 'doctor'`) وولي الأمر (`by: 'parent'`) وسكربت الترحيل (`by: 'migration'`). السجل للإضافة فقط.

## الحقول القديمة التي تُحذف

فوراً بعد نسخة احتياطية (لا يقرأها أي كود): `carbRatioByMeal` · `correctionFactorByMeal` · `cf_breakfast/lunch/dinner/snack` · `carbGoals` · `carbTargets` · `longActingDose` · `weightKg` · `severeHigh/Low(+Level)` · `mealsDoses` · `unitType`.

بعد تحديث كل القُرّاء (`--final`): `carbRatio` · `correctionFactor` · `normalRange` · `unit`.

## الاختبارات

```
node tests/protocol.test.mjs      # وحدة البروتوكول (20 حالة)
node tests/migrate.test.mjs       # سكربت الترحيل على قاعدة وهمية
```

## الخطة

1. وحدة البروتوكول والاختبارات والقواعد وأداة الترحيل (تجربة جافة): هذه الحزمة.
2. ربط الكتّاب: `child-edit` ثم `doctor-child` ثم `doctor-dashboard` ثم `add-child` ثم `visits`.
3. ربط القُرّاء: `dose-engine` والهيدر والمحركات المحلية في `child.js` و`parent.js` والتقارير.
4. الترحيل الفعلي (`--apply`) ثم `--final` بعد التأكد.
